# Учебное веб-приложение

Веб-приложение, разработанное с использованием Spring.

## Использованные технологии

- PostgreSQL
- Spring JDBC
- Spring Core
- Spring Web MVC
- Thymeleaf Spring 6
- Hibernate Validator
- Spring Validator

## Возможности веб-приложения

- создание, редактирование, удаление и просмотр пользователей;
- создание, редактирование, удаление и просмотр книг;
- создание и удаление связи между пользователем и книгами.
